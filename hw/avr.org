AVR chips require a 'programmer' and some software. 
- programmers
  - [[https://www.fischl.de/usbasp/][USBasp - USB programmer for Atmel AVR controllers - fischl.de]]
  - [[https://www.microchip.com/en-us/development-tool/ATAVRISP2][AVRISP MK2]]
  - [[https://www.microchip.com/en-us/development-tool/ATATMEL-ICE][ATMEL-ICE]]
  - [[https://www.microchip.com/en-us/development-tool/ATSTK500][STK500]]
- to run avrdude without superuser, a udev rule like the following is needed (common group name is =uucp=)
  #+begin_example
    # Set group for a programmer matching with vendor and product IDs
     SUBSYSTEM=="usb", ATTRS{idVendor}=="your Vendor ID", ATTRS{idProduct}=="your Product ID", GROUP="uucp", MODE="0666"
  #+end_example
