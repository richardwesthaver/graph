IDEs come in many forms and without any clear boundaries between what
is part of an IDE and what is not.

#+begin_quote
An integrated development environment (IDE) is a software application
that provides comprehensive facilities for software development. An
IDE normally consists of at least a source-code editor, build
automation tools, and a debugger.
#+end_quote
