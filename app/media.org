- No Linux builds available - MacOS/Windows only :'C
- As of [2025-04-06 Sun] I only use it for ocassional MIDI tracking of
  sheet music
- Some interesting [[https://help.ableton.com/hc/en-us/articles/209769625-Live-specific-file-types][file types]]:
  - als :: Ableton Live Set or template set, used for Live Sets and Templates.
  - alp :: Ableton Live Pack, a compressed version of an Ableton project containing the live set and related content.
  - ams :: Ableton meta sound, used for user-created waveforms in Operator.
  - amxd :: Ableton Max for Live device, used for Max for Live devices.
  - asd :: Ableton sample analysis file, contains analyzed audio data.
  - ask :: Ableton skin file, used for Live Themes.
  - adg :: Ableton Device Group.
  - adv :: Ableton Device Preset.
  - agr :: Ableton Groove.
  - alc :: Ableton Live Clip
- The format of most interest is =asd=

VELOCITYAMOUNT; CYCLEENERGIES;
HASUSERONSETS; HIDDENLOOPEND;
TIMESIGNATURE; TIMESIGNATUREDENOMINATOR;
LASTINDICES5; REMOTEABLETIMESIGNATURE;
SAMPLEOFFSET; SAMPLEVOLUME;
TIMESIGNATURENUMERATOR; DENOMINATOR; EXTRALENGTH;
INVNOTELENS; PITCHCOARSE; WARPMARKERS;

ONSETEVENT; PITCHMARKS; SAMPLEDATA; ISSET; USERFLOAT; BPMS;
FADE; LOCK; NAME; SYNC; ONSETS; HIQ

    points, BPM, KEY, etc
